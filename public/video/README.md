# Hero video asset

Place the generated cinematic portfolio video at:

`public/video/hero.mp4`

The hero is already wired to autoplay the MP4 silently, loop it, and use `public/images/northern-shore.png` as the poster/fallback frame.

For best performance, keep the video short and web-optimized (H.264 MP4, 1080p or lower, no audio track if it is not needed).
